# DevTrack

## Демо-режим

Регистрация, вход, выход, изменение имени профиля и сброс пароля работают без подключения к базе данных. Демо-аккаунты и учебный прогресс сохраняются только в `localStorage` текущего браузера, поэтому они недоступны на других устройствах и могут быть удалены очисткой данных браузера. Пароли в демо-режиме сохраняются в виде хеша, но этот режим не предназначен для реальных аккаунтов или конфиденциальных данных.

Из папки `frontend/` запустите приложение командой `npm run dev`. Сейчас авторизация, каталог и корзина работают в демо-режиме через `localStorage`.

## Помощник сайта

Плавающая кнопка DevTrack Assistant доступна на всех страницах и показывает пять готовых вопросов с ответами на кыргызском, русском и английском языках. Это FAQ-помощник с фиксированными ответами, а не подключённая языковая модель; API-ключ не требуется. Тексты находятся в `src/components/SiteAssistant.jsx`.

## Каталог и запись на курсы

В кабинете доступны каталог курсов (`/courses`), детали курса (`/item/:itemId`), панель управления (`/admin`), корзина (`/cart`) и оформление записи (`/checkout`):

- Поиск выполняется сразу при вводе; направление можно отфильтровать, а курсы — отсортировать по названию или цене.
- На `/admin` можно добавлять курсы с описанием, категорией, уровнем, длительностью и ценой, а также удалять их. Новые записи видны в каталоге, но для них ещё нужно подготовить учебные материалы.
- Откройте подробности курса по ссылке на его название или кнопке «Подробнее»; страница `/item/:itemId` показывает описание, параметры и цену и позволяет добавить курс в корзину.
- Для пробного урока выберите курс, дату не раньше завтрашнего дня и время.
- Страница оформления отправляет заказ в Django API, который сохраняет его в общей базе и отправляет уведомление в настроенный Telegram-чат. Оплата пока не проводится.
- Кнопка записи открывает отдельную страницу `/booking/:courseId`; название курса передаётся через `navigate` и `location.state`. Кнопка отмены возвращает в каталог `/courses`.
- В корзине можно менять количество курсов (от 1 до 10) и посмотреть общую стоимость.
- Переключатель KG / RU / EN находится в верхней панели кабинета. Словарь переводит навигацию, каталог и новые формы; существующие учебные материалы пока остаются на русском.

### Как устроены компоненты

- `src/context/AcademyContext.jsx` хранит каталог, корзину, заявки и бронирования.
- `src/context/LanguageContext.jsx` содержит словарь интерфейса и выбранный язык.
- `src/pages/CoursesPage.jsx` объединяет поиск, фильтры и каталог курсов.
- `src/pages/ItemDetailsPage.jsx` показывает подробности выбранного курса и кнопку покупки.
- `src/pages/AdminPage.jsx` содержит отдельную демо-панель управления курсами.
- `src/components/CourseCatalogCard.jsx` показывает курс и открывает страницу записи.
- `src/pages/BookingPage.jsx` проверяет и сохраняет запись на отдельной странице `/booking/:courseId`.
- `src/pages/CartPage.jsx` управляет корзиной, а `CheckoutPage.jsx` отправляет заказ в Django API.
- `src/pages/AcademyPage.module.css` содержит адаптивную сетку и модульные стили каталога.

Каталог, корзина, заявки, бронирования и выбранный язык пока сохраняются в `localStorage` этого браузера. Заказы, оформленные после подключения backend, хранятся в базе данных сервера и отправляются в настроенный Telegram-чат. Оплата не проводится, а переключатель демо-панели не является настоящей защитой администратора.

### Аналитика посещаемости курса

На странице курса блок аналитики запрашивает серверный endpoint `GET /api/courses/:courseId/analytics`, где `:courseId` — URL-кодированный идентификатор курса. Ответ должен быть JSON-объектом вида:

```json
{
  "totalVisits": 1234,
  "uniqueUsers": 256,
  "viewsByDay": [
    { "date": "2026-10-25", "views": 38 },
    { "date": "2026-10-31", "views": 42 }
  ]
}
```

Счётчики должны быть неотрицательными целыми числами, а даты — в формате `YYYY-MM-DD`; график показывает до семи последних дат из ответа API. Сервер в этом демо-проекте не реализован: до подключения endpoint блок покажет сообщение об ошибке, а не демонстрационные значения. Кнопки «Обновить» и «Повторить» заново запрашивают данные.

### Журнал посещаемости учеников

В нижней части `/admin` можно вручную добавить запись о фактическом посещении: ученика, курс, урок, дату и время и статус «Был на уроке» / «Пропустил». Записи хранятся в массиве `attendance` внутри `devtrack.academy.v1` в `localStorage` и показываются в таблице с фильтрами по имени и дате. Бронирование пробного урока не создаёт запись о посещении автоматически: бронь не подтверждает, что ученик пришёл. Для реального общего журнала между устройствами данные нужно хранить на сервере.

### Пользователи и журнал активности

В `/admin` список зарегистрированных аккаунтов показывает имя, электронную почту, роль, время последнего входа и примерный статус онлайн. Регистрация, вход, повторное открытие сайта, открытие урока и создание бронирования автоматически добавляются в журнал действий. Данные аккаунтов находятся в `devtrack.demo-auth.v1`; пароль и его хеш не попадают в таблицу или журнал активности. События активности ограничены последними 500 записями, а список обновляется при изменениях в приложении и в других вкладках этого браузера.

Это только локальное демо: `localStorage` не передаёт данные администратору между устройствами, а анонимного посетителя без аккаунта нельзя связать с именем и ролью. Статус «Онлайн» приблизительный и основан на активности авторизованного пользователя в видимой вкладке за последние 90 секунд. Для настоящего общего списка, аутентификации ролей и достоверного присутствия нужен сервер с базой данных и проверкой доступа к админ-панели.

## Каскадное появление страниц

`src/components/AnimatedPage.jsx` автоматически применяет последовательное появление основных блоков страницы, а на страницах с сеткой — её карточек. Обёртка уже подключена к публичным страницам и содержимому кабинета. Длительность и шаг задержки настраиваются в `src/index.css`; системная настройка `prefers-reduced-motion` отключает анимацию.

## Темы и типографика

Глобальные цвета, типографические токены, фокусные состояния и адаптивные стили находятся в `src/index.css`. Заголовки используют Space Grotesk, основной текст — DM Sans; Google Fonts подключены в `index.html`. Светлая и тёмная темы выбираются в `/settings` и сохраняются вместе с учебным прогрессом в `localStorage`. Начальная тема применяется до первой отрисовки страницы, чтобы избежать вспышки неверной палитры.

Чтобы добавить оформление к новому экрану, используй классы Tailwind проекта и общие токены CSS (`--canvas`, `--surface`, `--text-primary`, `--accent`, `--border-subtle`); для карточек и полей сохраняй читаемый контраст, видимый `:focus-visible` и поддержку `prefers-reduced-motion`.

## Backend integration

The Django API is maintained separately in the sibling `backend/` directory. The Vite development server proxies `/api` requests to Django at `http://127.0.0.1:8000`. Authentication, courses, and the cart still use demo/localStorage data; checkout orders are sent to the server API. See the repository README and `backend/README.md` for backend setup.
